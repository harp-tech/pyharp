# Examples

This section contains some examples to help you get started with `pyharp`.

Here's the complete list of available examples:

- [Getting Device Info](get_info.md) - connect to a Harp device and read its information.
- [Check Device ID](check_device.md) - connect to a Harp device and check its ID.
- [Wait for Events](wait_for_events.md) - connect to a Harp device and wait for events.
- [Write and Read from Registers](write_and_read_from_registers.md) - connect to a Harp device and read from registers.
